# Obsidian Res Relinker

### 场景一：把带图片的文字从 A 复制到 B（最常见的痛点）

假设你在 `A项目.md` 里贴了一张架构图，按照插件的规则，这张图存放在 `_RES/A项目/架构图.png`，笔记里的代码是 `![[_RES/A项目/架构图.png]]`。

现在，你觉得这段带架构图的文字写得很好，想把它**复制/粘贴**到 `B项目.md` 中。

- **没有插件时：** `B项目.md` 里的链接依然是 `![[_RES/A项目/架构图.png]]`。这就导致 B 强行依赖了 A 的图片。如果某天你把 A 项目归档或者删除了，B 项目里的这张图就彻底裂开了（找不到了）。
- **有插件时：** 当你把文字粘贴到 `B项目.md` 并触发保存时，插件瞬间察觉到：“当前笔记叫 `B项目`，但引用了一张 `_RES/A项目/...` 的图片，名字不匹配！”
  - 插件会自动在 B 旁边建一个 `_RES/B项目/` 文件夹。
  - 把 `架构图.png` 复制过去。
  - 把 `B项目.md` 里的代码瞬间自动改成 `![[_RES/B项目/架构图.png]]`。
  - *（注：如果是**移动版代码**，它会直接把图从 A 抢过来给 B）。*
